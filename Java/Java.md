### LAMBDA FUNTION
- En Java, el operador :: se refiere a una referencia de método, que es una forma simplificada 
  de escribir una expresión lambda para llamar a un método.  

### Key word 'this'  
-  La palabra clave 'this' se usa para hacer referencia al objeto actual en un método o constructor,  
    y para resolver ambigüedades en el código.
